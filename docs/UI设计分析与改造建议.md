# Cluster Intelligence 前端 UI 设计分析与改造建议

> 基于对 `src/app/globals.css`、`src/app/page.tsx`、`src/components/topology-graph.tsx`、`panels.tsx`、`inspector-panel.tsx` 的完整代码审计。

---

## 0. 设计定位一句话（Design Read）

**Reading this as:** 面向安全分析师的网络拓扑安全分析控制台（SOC graph console），采用"克制型指挥中心仪表盘"语言，而不是"展示型深色科技风"；视觉重心永远是画布上的图，UI 外壳应当退到第二层。

- 这个产品属于 **graph console / network-map console** 品类，对标：Neo4j Bloom、Elastic Security Graph、Datadog Network Map、Grafana NodeGraph、Gephi、Graphistry、Splunk Enterprise Security。
- 它不是 landing page、不是 portfolio、不是 marketing site——**它是一台仪表盘**。`design-taste-frontend` 技能明确说这类密集数据产品 UI 属于 Carbon / Fluent 一族的规范，而不是营销页美学。当前代码恰恰把大量营销页手法（玻璃拟态、发光、呼吸动画、噪点纹理）用在了仪表盘上——这就是"感觉不好"的根源。

## 1. 当前设计审计（代码事实）

### 1.1 你目前做了什么（摘要）

| 层 | 现状 |
| --- | --- |
| 主题 | 深色 "VOID COMMAND"：背景 `#050810`，主色 `#00e5c7` 青绿，异常 `#ff4d6a` 珊瑚红，警告 `#f0a030` |
| 外壳 | 顶部玻璃头栏 + 左侧 44px 图标工具栏 + 全屏画布 + 左侧滑出抽屉 ×4 + 右侧节点检查器（320px） |
| 材质 | 全站玻璃拟态：头栏/工具栏/抽屉/面板全部 `backdrop-filter: blur(12-20px) saturate(140-150%)`，叠加发光阴影 |
| 装饰 | `body::before` 顶部 60vh 径向渐变光晕、`body::after` 全屏噪点纹理、空态呼吸边框、按钮发光 hover |
| 字体 | `Bricolage Grotesque`（展示）+ `Plus Jakarta Sans`（UI）+ `JetBrains Mono`（数据），字号普遍 8-13px |
| 图渲染 | 节点半径 = 度数（大图 2-8 / 小图 4-16），节点填充 = `COMMUNITY_COLORS[community % 12]`，异常节点红色脉冲光环 ×2 + 红色 glow，跨域边青色虚线，域内边灰色，标签 8-9px 等宽 |
| 交互 | 单击选中 → 右侧检查器 + 邻居高亮；双击 → 1 跳邻居展开；hover tooltip；滚轮缩放 + 右下角 3 键缩放控件；三档布局预设 + 力参数滑杆 |

### 1.2 做得对的地方（保留）

1. **深色主题方向正确**——安全运营工具几乎都是深色，这不是问题。
2. **"异常 = 红色脉冲"是整站最有语义的信号**，保留。
3. **跨域/域内边用不同线型区分**（青色虚线 vs 灰实线）——方向对。
4. **已做无障碍基础**：skip link、aria-label、`prefers-reduced-motion`、`color-scheme`。
5. **图形编码基础正确**：节点大小 = 度数、边宽 = 权重（这是 D3 图的正确默认）。

### 1.3 问题诊断（按影响排序）

#### A. 视觉噪音与信号竞争（最伤观感的根源）
- **每个元素都在发光，等于没有元素在发光。** 同屏存在的发光/动画层：头栏阴影、`body::before` 渐变光晕、噪点纹理、stat-card 顶部发光线条、icon-toolbar 按钮 hover/active 发光、空态呼吸边框、节点 glow、异常双脉冲环、搜索闪烁、按钮 glow、FAB glow。安全分析师需要一眼定位"哪个节点异常"，而当前异常信号被淹没在装饰里。
- **玻璃拟态滥用**：`backdrop-filter` 面板悬浮在图上方时，图透过模糊层被"脏化"，面板文字与背景图混在一起难以阅读；且 blur 是与 D3 力模拟抢 GPU/主线程帧的已知性能杀手（3738 节点场景尤其明显）。
- 位置：`globals.css:207-232`（body 光晕+噪点）、`globals.css:239-278`（glass-panel/stat-card-glow）、`globals.css:504-521`（按钮 glow）、`topology-graph.tsx:333-403`（异常动画）。

#### B. 颜色编码双重语义 + 撞色
- **社区色和状态色混在同一通道**：节点颜色 = `community % 12`（12 色循环），异常又叠加红色描边/光环，选中又叠青色 glow——同一元素上"安全域 + 异常 + 选中"三种信号靠叠加表达，可读性崩塌。
- **12 色循环在 59 域时严重撞色**：你的真实数据是 59 个安全域，`% 12` 意味着第 12 个域和第 24 个域颜色一样，两个相邻视觉区域共享颜色，域的可区分性 = 0。这是"安全域划分"作为核心卖点却最不可读的地方。
- **主色 `#00e5c7` 青绿同时被用作**：品牌强调、选中 glow、跨域边、tooltip 标题、按钮 hover——跨域边和"选中态"撞色。
- 位置：`types.ts:137-151`（60 色板但图只取前 12）、`topology-graph.tsx:410-433`、`topology-graph.tsx:263-269`。

#### C. 可读性与信息密度失配
- **字号普遍过小**：节点标签 8-9px、面板正文 10-13px、tab 11px、统计数字 11px。SOC 大屏 + 密集数据场景，最小可读字号应 ≥ 12px，关键指标 ≥ 14px。8px 标签在 4K 大屏上基本是装饰性噪点。
- **展示字体 `Bricolage Grotesque` 不适合工具**：它的字符个性强（宽圆角、喇叭形），用于标题会让"指挥中心"气质变成"营销页气质"；工具型产品标题应使用中性 grotesque（Inter/Geist 级别）。
- **数字没有 `tabular-nums` 统一**（部分用 `font-mono` 部分没有），统计数字跳动、对不齐。
- 位置：`topology-graph.tsx:453`（8-9px）、`inspector-panel.tsx`（11px 密集区块）、`page.tsx:753`（`font-display` 标题）。

#### D. 空间心智模型缺失——"图"没有地图感
- 3738 节点力导向 = 一团线球。你**没有画安全域的区域边界**（convex hull / Voronoi / 分组包围），59 个域挤在一起时，用户无法回答"哪个域在哪、域和域怎么连接"——而这正是安全域分析的核心问题。
- **没有缩略图（minimap）**：大图缩放后完全丢失"我在图上的哪里"。
- **没有语义缩放（semantic zoom）**：放大/缩小只是缩放，标签策略、节点聚合、详情粒度不随 zoom 变化。大图场景标签全关（`isLargeGraph` 时 opacity 0），用户放大后也看不到标签。
- 位置：`topology-graph.tsx:445-459`（标签策略）、`topology-graph.tsx:156-164`（zoom 无语义）、`page.tsx:871-893`（聚焦域只是个角标）。

#### E. 信息架构与交互不一致
- **左侧同时堆了图标工具栏 + 4 个左滑抽屉**：4 个抽屉（数据源/算法/安全策略/统计）全部从左侧滑出，叠在工具栏上，切换时互相覆盖、深度混乱；右侧又有一个检查器。**左右开弓 + 左侧内卷**的布局让用户记不住"功能在哪"。
- **双击 = 展开邻居 与 拖拽节点冲突**：拖拽时误触双击概率高；且展开交互没有任何画布内视觉提示。
- **检查器 320px 太窄**，详情/Enrich/连接三 tab 挤在一起；统计面板（480px 左抽屉）内容与检查器重复（都是域列表+统计）。
- **缩放控件是右下角悬浮 3 键 + 滚轮**，与"聚焦域角标"（左上）"统计角标"（头栏）分散，操作记忆负担大。
- 位置：`page.tsx:811-847`（工具栏）、`page.tsx:951-1019`（4 个左抽屉）、`topology-graph.tsx:734-777`（缩放 FAB）。

#### F. 性能（结构性）
- 力模拟每 tick 全量更新所有 DOM 属性（`topology-graph.tsx:586-599`），加上 blur 滤镜（`feGaussianBlur` + 每节点 `filter`）、`backdrop-filter` 面板，大图帧率堪忧。数据转换注释里也写明"节点/边级 data-join 仍是全量重建"（见交接文档待办 4）。

## 2. 这类拓扑图适合什么样的前端 UI（核心回答）

### 2.1 品类结论

你的产品品类是 **"网络拓扑安全分析控制台"**，它应该向 **Neo4j Bloom / Elastic Security / Datadog Network Map / Grafana NodeGraph / Graphistry** 这类产品看齐，而不是向 Awwwards 深色科技营销页看齐。

这类 UI 的共性范式（也是你该抄的作业）：

| 范式 | 说明 |
| --- | --- |
| 图即主角 | 画布占 85%+ 面积；外壳是工具条，不是展示面 |
| 克制材质 | 面板用高不透明度深色或细边框分隔，不在图上叠 blur 玻璃 |
| 语义编码互斥 | 形状/大小/颜色/线型各自只表达一件事，禁止叠加 |
| 空间化安全域 | 域 = 画布上的区域（凸包/分组），域标签直接画在画布上，可点击 |
| 可扩展设计 | 聚合、缩略图、语义缩放、渐进渲染，从 212 到 3738 节点都成立 |
| 密度+可读性 | 大屏优先：字号 ≥ 12px、tabular numerals、字重层级分明 |

### 2.2 视觉语言五原则（改造方向）

**① 图是主角，chrome 退让**
- 头栏压缩到 48px 信息带（品牌 + 搜索 + 节点数 + 域数 + 主题），去掉装饰性光晕。
- 画布上的浮动面板全部改为**高不透明度深色**（`rgba(12,17,32,0.92)`）+ 1px 细边框，去掉或大幅降低 blur（仅在非图区域保留玻璃质感）。给 `prefers-reduced-transparency` 提供实底回退。
- 只保留一个动画信号：**异常脉冲**。其余装饰动画（呼吸边框、节点常亮 glow、浮动图标）全部删除或降到 0.5s 一次性入场。

**② 语义编码互斥分层**
| 通道 | 只表达 | 当前实现问题 |
| --- | --- | --- |
| 节点填充色 | 安全域 | ✅ 但 12 色循环撞色 → 改高区分度色板或区域色 |
| 节点大小 | 度数/流量 | ✅ |
| 节点描边 | 选中 / 聚焦 | ⚠️ 当前异常也占描边 → 异常改"光环"独占，描边只表选中 |
| 红色 + 脉冲 | 异常（唯一语义） | ✅ 保留并强化 |
| 边宽/不透明度 | 权重 | ✅ |
| 边色 | 域内/跨域 | ⚠️ 跨域青色与主色撞 → 改琥珀色或中性高亮 |
| 青色 | 仅"当前交互/主操作" | ⚠️ 现在同时是品牌色+跨域+选中+tooltip |

**③ 空间化安全域（性价比最高的一步）**
- 用 `d3.polygonHull` 给每个安全域画**半透明凸包背景** + 域级标签（如 "域 12 · Web"）直接放画布上，leader line 指向域内节点。
- 域凸包颜色用高区分度色板；域内节点填充改**中性色**（灰白），避免节点色和域色双重噪音——"域"是色块，"节点"是点，层次立刻清晰。
- 点击凸包 = 聚焦该域（已有 `focusedCommunity` 状态，直接复用），凸包内的节点高亮，域外节点降透明。
- 这是把"59 个域"从数据变成"看得见的地图"的关键。

**④ 可扩展性**
- **聚合**：度数/域规模超阈值时，按子网或域聚合成"超节点"（显示 `+N`），展开才显示内部——3738 节点首屏只画聚合层。
- **缩略图**：右下角 120px minimap（复用 zoom transform），替代现在的 3 键悬浮块（缩放用滚轮 + minimap 拖动即可）。
- **语义缩放**：`zoom.k > 1.5` 才显示标签；`k > 3` 才显示端口/协议；`k < 0.6` 只画凸包。标签渲染从 8px 提到 11-12px。
- **渲染**：把 `feGaussianBlur` 每节点 filter 换成 CSS 类（`filter: drop-shadow`）或只在异常/选中节点上用 SVG filter；力模拟 tick 用 `requestAnimationFrame` 节流。

**⑤ 密度与可读性**
- 最小字号 12px（数据标签 11-12px，正文 13px，标题 15-16px），关键指标 14-16px + `font-variant-numeric: tabular-nums`。
- 字体收敛：UI 用中性 sans（Inter/Geist 级别），**移除 Bricolage Grotesque**，数据仍用 JetBrains Mono；全站统一一个字体栈，不再混 `font-display`。
- 文本层级固定三档：标题（semibold 15px）/ 标签（medium 12px muted）/ 数据（regular 13px tabular）。

### 2.3 参照产品（去抄它们的气质）

- **Neo4j Bloom**：深色画布 + 干净低饱和节点色 + 搜索优先，UI 几乎隐形。
- **Elastic Security**：左导航 + 主画布 + 右侧详情抽屉，紧凑信息架构教科书。
- **Datadog Network Map**：把网络画成"地图"，有区域、方向箭头、聚合节点。
- **Grafana NodeGraph**：节点色相 = 状态、紧凑标签、hover 聚焦。
- **Graphistry**：百万节点大图的聚合与渐进渲染标杆。

## 3. 分模块改造清单（映射到代码）

### 3.1 画布层 `topology-graph.tsx`（P0）

1. **域凸包渲染**：`d3.polygonHull(nodes.map(n => [n.x, n.y]))`，每个 community 一个 `<path>`，半透明填充 + 细描边；域标签 `<text>` 放凸包质心，点击 = `onToggleFocus`。→ 复用现有 `focusedCommunity` 数据流，改动集中在渲染层。
2. **节点填充改中性色**（`#8b95ad` 灰或浅青），异常/选中/白名单用描边+光环表达；域信息交给凸包颜色。
3. **跨域边改琥珀色** `rgba(240,160,48,0.5)`，域内边灰色——去掉与主色的撞色。
4. **语义缩放**：在 zoom handler 里按 `event.transform.k` 切换标签/聚合/凸包显示。
5. **minimap**：右下角小 SVG，渲染 `zoomTransform` 视口矩形；删除 3 键悬浮块或并入 minimap。
6. **性能**：SVG filter 只用于异常/选中节点；tick 回调 `requestAnimationFrame` 节流；`feGaussianBlur` 的 `stdDeviation` 降低。

### 3.2 外壳层 `page.tsx` / `globals.css`（P0）

7. **删装饰**：`body::before` 60vh 光晕改 1 个 10vh 顶部微光或删除；噪点纹理 opacity 0.035 → 0 或 0.015；删除 `stat-card-glow`、`btn-glow` 发光、空态呼吸边框。
8. **材质收敛**：`.glass-panel` / `.sheet-drawer-glass` / `.app-header` 的 `backdrop-filter` 降为 `blur(8px)` 且面板底色提到 `0.92` 不透明度；新增 `@media (prefers-reduced-transparency)` 实底回退。
9. **字号与字体**：移除 `--font-display: Bricolage Grotesque`；基础字号调大；数字统一 `tabular-nums`。
10. **抽屉统一**：4 个左抽屉改为 **1 个左抽屉 + 内部 tabs**（数据源/算法/安全策略/统计），或统计并入右侧检查器体系；左抽屉不再叠在工具栏上（工具栏固定，抽屉从工具栏右侧展开）。
11. **头栏压缩**：合并角标（节点数/域数）为一行紧凑状态条。

### 3.3 面板层 `panels.tsx` / `inspector-panel.tsx`（P1）

12. **检查器加宽**（320 → 400px），详情 tab 信息分组：身份（IP/角色/域）/ 流量（出入/字节）/ 风险（异常分/等级）/ 属性（端口/协议/CMDB）。
13. **统计面板与检查器分工**：统计 = 全局视图（KPI 卡 + 域列表 + 可信度），检查器 = 单点视图；避免域列表重复出现两处。
14. **空态/加载态**：画布空态保留（这是全站最完整的空态），面板加 skeleton 而非 spinner。

### 3.4 动效纪律（P1）

15. 保留：异常脉冲、聚焦过渡、抽屉滑入。删除：节点常亮 glow、呼吸边框、浮动动画。
16. 所有动画 ≤ 300ms ease-out；`prefers-reduced-motion` 已有全局覆盖（保留）。

### 3.5 颜色系统建议 token（P1）

```
背景：#050810 → #0c1120（面板）→ #131a2e（抬升）
主强调：#00e5c7（仅交互/选中，不再用于跨域边）
中性文本：#e0e6f0 / #94a3b8 / #5a6680
状态：异常 #ff4d6a（唯一脉冲语义）| 警告 #f0a030 | 正常 #22d67a | 跨域边 #f0a030
域色板：金黄角 HSL 高区分度 60 色（hue 步进 137.5°，固定 s/l），保证 59 域不撞色
```

## 5. 一句话总结

你的图本身（编码、交互、动画语义）方向是对的，问题出在**外壳把图给"包装"坏了**：满屏发光玻璃营销页手法 + 12 色撞色 + 8px 字号 + 没有空间化的安全域。改造的锚点只有一个——**"让画布上的图成为唯一的主角，外壳退到工具条的位置，安全域画成看得见的地图，红色只留给异常"**。
